## 目的

## 構成
- index.html：御守り・御朱印・その他授与品の仮カード
- style.css：CSS Flex/overflow-x/scroll-snap、余白と縦スクロール対策
- slider.js：左右矢印・ナビゲーションの有効無効。外部ライブラリなし
- 自動再生なし。勝手な遷移なし。スマホのタッチ横送りはCSSネイティブ

## 合格条件
1. PC: 左右矢印を押すと1枚ずつ移動
2. スマホ: 横スワイプ、他の縦スクロールを妨げない
3. Notion: WebページURL埋め込み、黒余白・ファイル名・枠内縦スクロールなし
4. 仮画像のまま本番公開しない
5. 実物写真が揃ったら内容・掲載順・画像リンク先を本人確認
6. 本番Notionには本人承認後のみ追加、3つの既存ボタンや点滅版を変更しない
